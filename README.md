## 参与维护

通过 [Issue](https://github.com/hvoyai/awesome-free-token/issues) 或 [Pull Request](https://github.com/hvoyai/awesome-free-token/pulls) 补充资源、纠错或报告失效活动。请附官方活动页、文档或定价页；邀请链接需披露奖励关系，并附无推广参数的入口。

```markdown
### 平台 / 活动名称

- 官方入口：
- 官方规则或定价来源：
- 福利类型：每日 / 每月 / 新人 / 限时 / 学生 / 免费调用
- 免费额度与单位：
- 使用方式：API / 产品内 / 指定云服务内
- 适用模型与排除项：
- 领取条件：
- 刷新周期与时区：
- 活动截止日期：YYYY-MM-DD / 官方未公布
- 额度到账后的有效期：
- 超额处理：停止服务 / 扣积分 / 自动付费 / 待确认
- 商用、隐私及其他限制：
- 实际核实日期：YYYY-MM-DD
```

维护规则：

- 核实日期对应实际查阅官方规则或控制台的日期，个人实测单独注明。

- 日期写成 `YYYY-MM-DD`；活动结束、模型下架或权益变更时标记失效。
- 不在 Issue、PR 或截图中公开 API Key、手机号、身份证等敏感信息。
