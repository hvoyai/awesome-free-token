> 收集 AI 免费 Token、API 试用额度、产品积分与限时福利，让免费资源更好找，也让使用限制更清楚。

不是所有「免费额度」都能拿来调 API。本项目同时收录开发者资源与 AI 产品内福利，并尽量写清楚 **领多少、多久领一次、能用在哪、有什么限制、超额是否收费**。

**合法领取，按需使用。** 不提供批量注册、绕过实名、突破限额或其他违反平台规则的教程。

## 阅读前先看

- **资料状态**：本版根据提供的福利清单整理，整理日期为 **2026-11-10**；尚未逐项独立核验。
- **日期含义**：表格中的「原清单核实」沿用原始资料的标注，不代表本仓库已完成核实。未注明年份的日期按本次清单的 2026 年语境整理，活动年份及截止时间仍需以官方公告为准。
- **领取入口**：仅保留资料中明确给出的产品域名或规则页，不猜测「去领／去用」地址。这些入口尚未独立验证，不代表活动背书；缺失入口的条目欢迎补充官方来源。
- **补充资料**：第二批资料中的「自动 Verified」「今日验证」「多源直核」等是来源方自述，本仓库不继承其认证状态；「几天前」也不转换为实际核实日期。新增线索统一列入待核实区。
- **额度不能混算**：Token、积分、Credits、智点、算力、Neurons、PU 等不是同一种计量单位；不同平台的积分也不能直接比较或相加。
- **免费不等于不会扣费**：部分平台免费额度用尽后会自动转为付费、扣现金余额或消耗套餐。调用前请检查预算、限额与余额提醒。
- **模型与权益会变化**：下列型号、套餐、限免范围均按原清单保留，并非本仓库对模型已上线或当前可用的保证。「所有模型」仅指该活动所述产品及套餐范围，不代表厂商全部模型或服务。

## 领取前检查清单

- [ ] 进入的是官方域名、官方客户端或官方小程序，不是要求转账或索要密钥的第三方页面。
- [ ] 你要的是可调用的 API 额度，还是仅能在客户端使用的积分？
- [ ] 账号所在地区、产品版本、实名状态和学生资格是否符合要求？
- [ ] 领取时间、刷新时间、活动截止时间和到账后的有效期是否明确？这些时间不一定相同。
- [ ] 免费额度是账号共享、模型独立，还是多个功能共用？
- [ ] 免费用量耗尽后，是停止服务、扣积分、扣套餐，还是自动按量付费？
- [ ] 是否需要绑定银行卡、支付宝或云账号？是否能设置预算及费用告警？
- [ ] 生成内容能否商用、是否需要署名，输入内容是否会用于训练？
- [ ] 不同活动能否叠加？不要默认日赠、月赠、新人赠送可以累加。

## 参与维护

欢迎通过 [Issue](https://github.com/hvoyai/awesome-free-token/issues) 或 [Pull Request](https://github.com/hvoyai/awesome-free-token/pulls) 补充、纠错和报告失效活动。

优先补充 **官方活动页、官方文档、官方定价页**，不要只给邀请码、推广短链或无法追溯的截图。存在邀请奖励或推广关系时，请明确披露，并优先提供无推广参数的官方入口。

新增或更新条目时，建议提供：

```markdown
### 平台 / 活动名称

- 官方入口：
- 官方规则或定价来源：
- 福利类型：每日 / 每月 / 新人 / 限时 / 学生 / 免费调用
- 免费额度与单位：
- 使用方式：API / 产品内 / 指定云服务内
- 适用模型与排除项：
- 领取条件：
- 刷新周期与时区：
- 活动截止日期：YYYY-MM-DD / 官方未公布
- 额度到账后的有效期：
- 超额处理：停止服务 / 扣积分 / 自动付费 / 待确认
- 商用、隐私及其他限制：
- 实际核实日期：YYYY-MM-DD
```

维护约定：

1. **先补来源，再标核实**：只有实际查看过官方规则或控制台后，才更新核实日期；区分官方声明与个人实测。
2. **保留限制**：不把产品积分写成通用 API 余额，不把指定模型限免写成全平台免费。
3. **使用绝对日期**：不要写会随时间失真的「还剩 5 天」「今天截止」。
4. **失效及时标记**：活动结束、模型下架或权益变更时，注明失效或移入历史记录。
5. **不做模糊折现**：除官方直接发放的货币额度外，不将 Token 或积分统一估算成人民币；不同型号、输入输出比例和计费规则会产生很大差异。
6. **保护隐私**：请勿在 Issue、PR 或截图中公开 API Key、手机号、身份证信息或其他敏感数据。
